📌 Proyecto: Grafos - Estados de México
📖 Descripción

Este proyecto implementa un programa en Python que modela un conjunto de 7 estados de la República Mexicana utilizando la estructura de datos grafo.

El sistema permite representar conexiones entre estados junto con sus costos de traslado, así como realizar diferentes recorridos y cálculos asociados.

🎯 Objetivos
Implementar un grafo usando diccionarios
Representar estados como nodos
Representar conexiones como aristas con peso
Resolver recorridos con y sin repetición
Calcular costos de traslado
Visualizar el grafo
⚙️ Funcionalidades

✔ Mostrar estados y sus relaciones
✔ Recorrer todos los estados sin repetir (DFS)
✔ Recorrer estados permitiendo repetición
✔ Calcular costo total de cada recorrido
✔ Dibujar el grafo con sus pesos

🧩 Estados utilizados
Yucatán
Campeche
Quintana Roo
Tabasco
Veracruz
Puebla
Oaxaca
Chiapas
🧠 Algoritmos utilizados
DFS (Depth First Search) → recorrido sin repetir
Recorrido manual → para permitir repetición
Grafo no dirigido con pesos
📊 Salida esperada
Lista de estados y conexiones
Recorrido sin repetición + costo
Recorrido con repetición + costo
Visualización gráfica del grafo
📌 Conclusión

Este proyecto demuestra el uso de grafos para modelar problemas reales de rutas y costos, aplicando conceptos fundamentales de estructuras de datos y algoritmos de recorrido.
