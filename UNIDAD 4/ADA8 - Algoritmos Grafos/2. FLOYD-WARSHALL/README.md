# Algoritmo de Floyd-Warshall

## 📌 Descripción
El algoritmo de Floyd-Warshall permite calcular las distancias mínimas entre todos los pares de nodos en un grafo ponderado.

---

## 🧠 Fundamento
Se basa en programación dinámica, evaluando si un camino indirecto es más corto que uno directo.

---

## ⚙️ Funcionamiento
Se utiliza una matriz de distancias y se actualiza mediante nodos intermedios.

---

## 📊 Complejidad
- Tiempo: O(n³)
- Espacio: O(n²)

---

## 🚀 Aplicaciones
- Análisis de redes
- Optimización global de rutas
