# Método de Intercalación

## Descripción

El método de intercalación consiste en unir dos listas previamente ordenadas en una sola lista ordenada.

Este método es utilizado frecuentemente en algoritmos de mezcla y ordenamientos externos.

---

## Funcionamiento

1. Comparar el primer elemento de ambas listas.
2. Insertar el menor en la lista resultado.
3. Avanzar en la lista correspondiente.
4. Repetir hasta terminar ambas listas.

---

## Complejidad

- Tiempo: O(n)
- Espacio: O(n)

---

## Ventajas

- Muy eficiente para fusionar listas ordenadas.
- Base del algoritmo MergeSort.

---

## Desventajas

- Requiere listas previamente ordenadas.
- Utiliza memoria adicional.
