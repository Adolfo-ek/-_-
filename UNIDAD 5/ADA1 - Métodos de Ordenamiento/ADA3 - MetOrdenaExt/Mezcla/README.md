# Método de Mezcla Directa

## Descripción

La mezcla directa es un método de ordenamiento basado en dividir una lista en partes pequeñas y luego fusionarlas de forma ordenada.

También es conocido como MergeSort.

---

## Funcionamiento

1. Dividir la lista en dos partes.
2. Ordenar cada parte recursivamente.
3. Mezclar ambas partes ordenadas.
4. Repetir hasta ordenar toda la lista.

---

## Complejidad

- Mejor caso: O(n log n)
- Caso promedio: O(n log n)
- Peor caso: O(n log n)

---

## Ventajas

- Muy eficiente.
- Mantiene estabilidad.
- Bueno para grandes volúmenes de datos.

---

## Desventajas

- Consume memoria adicional.
- Implementación más compleja.
