# Métodos de Ordenamiento Externo en Python

## Descripción General

En este proyecto se desarrollaron tres métodos de ordenamiento externo utilizando el lenguaje de programación Python.

Los algoritmos implementados permiten comprender cómo se organizan grandes volúmenes de datos mediante técnicas de mezcla e intercalación, las cuales son utilizadas en sistemas de archivos, bases de datos y procesamiento masivo de información.

---

# Métodos Implementados

## 1. Intercalación

El método de intercalación consiste en unir dos listas previamente ordenadas en una sola lista ordenada.

### Características

- Fusiona listas ordenadas.
- Base de muchos algoritmos externos.
- Muy eficiente para combinar datos.
