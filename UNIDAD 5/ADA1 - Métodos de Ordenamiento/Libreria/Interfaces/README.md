# 🖥️ Carpeta Interfaces - Interfaces Gráficas del Sistema

## 📌 Descripción

La carpeta `interfaces/` contiene las interfaces gráficas del proyecto desarrolladas en Python utilizando Tkinter.

Estas interfaces permiten al usuario interactuar visualmente con los algoritmos, estructuras de datos y métodos de ordenamiento implementados en el sistema.

---

# ⚙️ Funcionalidades

- Interfaces gráficas interactivas
- Navegación entre ventanas
- Ejecución de algoritmos
- Visualización de resultados
- Animaciones de ordenamiento
- Comparación de algoritmos
- Carga y exportación de archivos
