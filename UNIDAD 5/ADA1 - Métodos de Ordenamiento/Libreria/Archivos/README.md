# 📁 Carpeta Archivos - Librerías de Manejo de Archivos

## 📌 Descripción

La carpeta `archivos/` contiene las librerías encargadas del manejo, lectura y almacenamiento de archivos dentro del proyecto.  

Estas librerías permiten trabajar con distintos formatos utilizados en los algoritmos y estructuras de datos, facilitando la importación y exportación de información.

---

# ⚙️ Funcionalidades

- Leer archivos TXT
- Guardar archivos TXT
- Leer archivos CSV
- Guardar archivos CSV
- Leer archivos Excel
- Guardar archivos Excel
- Manejo de codificación UTF-8
- Exportación de resultados
- Procesamiento de datos
