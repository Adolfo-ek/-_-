# 🛠️ Carpeta Utilidades - Herramientas y Funciones Auxiliares

## 📌 Descripción

La carpeta `utilidades/` contiene funciones auxiliares y herramientas de apoyo utilizadas por los distintos módulos del sistema.

Estas utilidades facilitan tareas comunes como validaciones, generación de datos, manejo de tiempos, gráficos y funciones reutilizables para mejorar la organización del proyecto.

---

# ⚙️ Funcionalidades

- Funciones auxiliares
- Validación de datos
- Generación de datos aleatorios
- Medición de tiempos
- Manejo de gráficos
- Herramientas reutilizables
- Soporte para interfaces y algoritmos
