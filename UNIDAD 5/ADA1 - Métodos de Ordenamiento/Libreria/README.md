# 📚 Librerias - Sistema Modular de Algoritmos y Estructuras de Datos

## 📌 Descripción

`Librerias_2.0` es un proyecto modular desarrollado en Python que integra algoritmos de ordenamiento, métodos de búsqueda, estructuras de datos, manejo de archivos e interfaces gráficas.

El sistema está diseñado para facilitar el aprendizaje, visualización y análisis de algoritmos mediante una arquitectura organizada, reutilizable y escalable.

---

# ⚙️ Funcionalidades principales

- Algoritmos de ordenamiento interno
- Métodos de ordenamiento externo
- Algoritmos de búsqueda
- Estructuras de datos
- Manejo de archivos TXT, CSV y Excel
- Interfaces gráficas interactivas
- Comparación de algoritmos
- Medición de tiempos
- Generación de gráficas
- Exportación de resultados
