# 💾 Carpeta Externos - Métodos de Ordenamiento Externo

## 📌 Descripción

La carpeta `externos/` contiene las implementaciones de algoritmos de ordenamiento externo utilizados para trabajar con grandes volúmenes de información almacenados en archivos.

Estos métodos permiten ordenar datos que no pueden cargarse completamente en memoria RAM, utilizando técnicas de lectura y escritura en archivos.

---

# ⚙️ Funcionalidades

- Ordenamiento de archivos grandes
- Lectura y escritura de bloques
- Manejo de archivos temporales
- Procesamiento de datos externos
- División y mezcla de información
- Exportación de resultados
