# ⚙️ Carpeta Internos - Métodos de Ordenamiento Interno

## 📌 Descripción

La carpeta `internos/` contiene las implementaciones de algoritmos de ordenamiento interno desarrollados en Python.

Estos métodos trabajan directamente en memoria RAM y son utilizados para organizar datos mediante diferentes técnicas de comparación e intercambio.

---

# ⚙️ Funcionalidades

- Ordenamiento de listas
- Comparación de algoritmos
- Visualización de procesos
- Medición de tiempos
- Intercambio de datos
- Procesamiento interno en memoria
