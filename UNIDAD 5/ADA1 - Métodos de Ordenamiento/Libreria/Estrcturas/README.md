# 🏗️ Carpeta Estructuras - Estructuras de Datos en Python

## 📌 Descripción

La carpeta `estructuras/` contiene las implementaciones de distintas estructuras de datos utilizadas dentro del proyecto.

Estas estructuras permiten organizar, almacenar y manipular información de manera eficiente para el desarrollo de algoritmos y aplicaciones.

---

# ⚙️ Funcionalidades

- Almacenamiento de datos
- Inserción de elementos
- Eliminación de elementos
- Búsqueda de información
- Recorrido de estructuras
- Manipulación dinámica de datos

---
