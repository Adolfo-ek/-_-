# 🔍 Carpeta Búsquedas - Algoritmos de Búsqueda en Python

## 📌 Descripción

La carpeta `busqueda/` contiene las librerías y algoritmos encargados de realizar distintos métodos de búsqueda dentro de estructuras de datos y colecciones.

Estos algoritmos permiten localizar elementos de manera eficiente utilizando diferentes técnicas de búsqueda secuencial y optimizada.

---

# ⚙️ Funcionalidades

- Búsqueda secuencial
- Búsqueda binaria
- Comparación de rendimiento
- Medición de tiempos
- Búsqueda en listas y arreglos
- Visualización de resultados
