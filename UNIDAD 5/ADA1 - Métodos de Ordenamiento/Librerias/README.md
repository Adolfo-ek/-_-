# Proyecto de Búsqueda Binaria en Python

## Descripción General

Este proyecto implementa diferentes variantes del algoritmo de búsqueda binaria utilizando Python.

La búsqueda binaria es un método eficiente para encontrar elementos dentro de una colección ordenada, reduciendo considerablemente el número de comparaciones realizadas.

El proyecto fue desarrollado como práctica de estructuras de datos y algoritmos.

Métodos Implementados
1. Búsqueda Binaria Iterativa

Realiza la búsqueda utilizando ciclos while.

Características
Método rápido y eficiente.
Menor consumo de memoria.
Complejidad O(log n).
2. Búsqueda Binaria Recursiva

Implementa la búsqueda utilizando recursividad.

Características
Código más elegante.
Fácil comprensión teórica.
Complejidad O(log n).
3. Buscar Todas las Ocurrencias

Permite localizar todas las posiciones donde aparece un elemento repetido.

Características
Funciona con listas ordenadas.
Soporta elementos duplicados.
4. Buscar el Elemento Más Cercano

Encuentra el valor más cercano cuando el elemento exacto no existe.

Características
Útil en aproximaciones numéricas.
Aplicable en análisis de datos.
Requisitos
Python 3.x
