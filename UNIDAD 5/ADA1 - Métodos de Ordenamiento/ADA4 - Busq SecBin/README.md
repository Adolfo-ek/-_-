# Proyecto de Búsqueda Binaria en Python

## Descripción General

Este proyecto implementa diferentes variantes del algoritmo de búsqueda binaria utilizando Python.

La búsqueda binaria es un método eficiente para encontrar elementos dentro de una colección ordenada, reduciendo considerablemente el número de comparaciones realizadas.

El proyecto fue desarrollado como práctica de estructuras de datos y algoritmos.
